# Deploy failure diagnosis

- `*-image-*`: bad image tag → "Container image tag or platform was not found", with an excerpt and an Open Compose link.
- `*-yaml-*`: invalid Compose YAML.
- `*-exit137-*`: killed / exit 137.
- `*-deploys.png`: the Deploys row card. `*-overview.png`: the Overview card. `*-fix-tab.png`: where the fix link lands.
- `*.log`: the raw build logs.
- `after.mp4`: the full flow.
- Before (main): failed rows only showed "Error".

Local test stack only. Throwaways were removed.
