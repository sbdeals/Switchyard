# Auto-deploy settings proof

Local dashboard: http://127.0.0.1:3045, built from /workspace/wt-autodeploy-settings.
Backend: local Dokploy v0.30.10. No application deployment was started.

The throwaway Git-backed compose service used the public source https://github.com/docker/awesome-compose.git (master; nginx-golang/compose.yaml). It was created, switched off with watch paths, reloaded, switched on, and reloaded again. Each state was independently read through compose.one.
